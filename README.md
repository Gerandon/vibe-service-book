# Vibe Service Book

A vibe coded web application for managing vehicle service books with shared access.

## Overview

- Manage multiple vehicles and their service records
- Share vehicles with collaborators
- Export service history to PDF
- NGXS state management with session storage
- Angular 21 + Bootstrap UI

## Development

```sh
npm install
npm start
```

## GitHub Pages

```sh
npm run deploy
```

This publishes the production build to GitHub Pages under `/vibe-service-book/`.

## Routes

- `/login` - authentication
- `/dashboard` - service book dashboard
